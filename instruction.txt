  Типы SQL-запросов:

  - WHERE (фильтры по реальным значениям из БД) — 97%
  - JOIN (6 видов соединений между таблицами) — 2.4%
  - COUNT — 0.5%
  - GROUP BY / ORDER BY / AGGREGATE / SELECT * — остальное

  Что включено:

  - Фильтры по реальным именам пассажиров, городам, аэропортам, кодам самолётов
  - JOIN-запросы: tickets↔segments, tickets↔bookings, flights↔routes, boarding↔tickets,
   routes↔airplanes, seats↔airplanes
  - Агрегаты: SUM, AVG, MIN, MAX, COUNT с GROUP BY
  - Подзапросы: "бронирования выше средней суммы", "пассажиры с более чем 2 билетами"
  - ILIKE для нечёткого поиска по имени
  - BETWEEN для диапазонов цен/сумм
  - Рандомизированные LIMIT (1, 3, 5, 10, 15, 20, 25, 50, 100)

  Для запуска обучения на новом датасете:
  ./build/bin/train_model --data training_data/bookings_1m_dataset.json \
      --out models/seq2seq_bookings_1m_attn \
      --epochs 30 --batch 64 --emb 256 --hid 512 \
      --dropout 0.1 --beam 3 --tf-start 1.0 --tf-end 0.5
